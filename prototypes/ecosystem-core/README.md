# 試作 04: 生態系の核

## 確かめる問い

YZRS Times の号を入力にして、惑星と生き物が互いを変え合う単純なルールを回したとき、号を重ねるだけで「たどりたくなる歴史」が生まれるか。毎回同じ結末（全滅、一種独占、停滞）に偏らないか。

## 動かし方

```text
node ledger.mjs <graph.json> ledger.json   # 入力台帳を作る（既存の号は凍結、新しい号だけ追記）
node run.mjs                                # 実データの全史、決定論テスト、長期運転テスト（history.json, soak.json）
node build.mjs                              # viewer.html に計算コードと台帳を埋め込んで index.html を作る
```

`index.html` はブラウザで開くだけで動く。創刊号から全史をブラウザで計算し直し、Node の結果とハッシュが一致するかを表示する。

`graph.json` は `yzrswork-site` の公開データ（`https://raw.githubusercontent.com/yzrswork/yzrswork-site/main/public/data/graph.json`）。Times 側には何も書き込まない。

## 仕組み

- 1号 = 2,000万年（号の中を100万年ずつ20回計算）。238号で約48億年。
- 気候: 恒星の明るさ（暗い若い恒星がだんだん明るくなる）、アルベド（氷と生き物の色）、CO2 の温室効果、酸素がない時代のメタン温室。CO2 は火山の放出と風化の釣り合いへ少しずつ近づく（炭素とケイ酸塩のサーモスタット）。-12℃を下回ると全球凍結し、風化が止まって CO2 がたまると解ける。
- 酸素: 光合成で生まれ、鉄などの還元物質に吸われる。吸いきると大気にたまる（大酸化イベント）。
- 生命: 条件が揃うと海で誕生。系統ごとに最適温度、温度の許容幅、体の色（アルベド）、光合成の有無、複雑さ（1〜5）を持ち、Daisyworld 型の成長と死、分岐、複雑化、陸上進出、絶滅を計算する。
- 記事が起こす事件: gem の記事は隕石の確率を上げ、記事の平均温度は火山活動を強め、熱い号では洪水玄武岩が起きうる。新しいキーワードの数は分岐と革新を起こりやすくする。
- 定数は `constants.mjs` に、意味、単位、出典、状態（合意、論争、思弁）付きで置いた。
- 決定論: 乱数は種と号の内容からだけ作る。計算は四則演算と `Math.sqrt` だけ（対数は自前の級数）。

## 結果

- 決定論テスト: 同じ台帳と種で2回計算した全史のハッシュが一致。ブラウザ（Chromium）の計算結果も Node と一致（約150ms）。
- 実データ238号の歴史（種 `times-garden-v1`、恒星は青白い恒星）: #6 最初の生命、#8 光合成、#42 大酸化イベント、#43 真核生物、#68 多細胞、#69 陸上進出、#82 巨大隕石から全球凍結で生命が全滅、#97 生命がふたたび誕生、#165 大型の生き物、#231 巨大隕石で系統の83%が絶滅。
- 長期運転テスト（合成の号1000号 x 40本）: 生命が生まれない 0%、最後に全滅 13%、最後に灼熱 13%、ずっと凍結 0%、一種独占 0%、最後の500号で大きな出来事なし 0%、全球凍結 平均4.3回、大量絶滅 平均4.9回、考える生き物への到達 8%。
- 課題:
  - 大酸化、多細胞、大型の生き物、陸上進出に 100% 到達しており、進化の段階が決まった道すぎる。時期は揺れるが、到達しない世界もあったほうが驚きがある。
  - 1号の中で凍って解けた全球凍結は、号ごとの記録には温度の落ち込みとして残らない。
  - 青白い恒星の世界では CO2 が下限（10ppm）に張り付いた。
  - 惑星を号ごとに作る（見た目の試作）か、1つの惑星の連続した歴史にするか（この試作）は未決定。この試作は創刊号から続く1つの惑星にした。
