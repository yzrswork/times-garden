# 試作 06: 時間の流れ方

## 確かめる問い

1号の時間を時代で変える（生き物の時代ほど細かくする）と、主役の惑星を何年も「覗くたびに驚きがある」状態で保てるか。

## 動かし方

```text
node run.mjs   # 案ごとに、主役の惑星の263号と、5年先までの未来（20通り）、合成の世界40本の5年ぶんを計算する（約2分。results.json）
```

本番の `engine/` を読むだけで、書き換えない。台帳は `data/ledger.json`（#263 まで）。

## 仕組み

- `flow.mjs`: 本番の `engine/world.mjs` の `stepIssue` を写し、時間の部分だけ変えた。1号の中は100万年ずつ計算し（本番と同じ刻み）、1号あたりの回数を時代で変える。号ごとに決まる事件（隕石、洪水玄武岩、大陸の育ち方）は、1号の時間に合わせて確率と量を縮める。超大陸の周期は、号の数ではなく時間で決める。
- 1号が2000万年の設定では、本番とビット単位で同じ（`run.mjs` の最初で確かめる）。
- 比べた案（`constants.mjs`）:
  - `eco-1`: いまの本番。いつも2000万年。
  - `A`: 大型の生き物が現れたら100万年。
  - `B`: 段階ごとに細かく（生命の前2000万年、生命1000万年、多細胞400万年、大型100万年）。
  - `D1`、`D2`、`D5`: #264 から100万年、200万年、500万年。#263 までの歴史は本番と同じ。
- 主役の惑星の未来は、実際の号の特徴を並べ替えた架空の号で、#264 から3650号（1日2号で5年）先まで回した。

合成の世界（40本、創刊号から5年）で5年後に生き物がいる割合: eco-1 23%、A 88%、B 90%、D1 90%、D2 90%、D5 88%。1年目の1日あたりの目立つ出来事: eco-1 0.22、A 0.10、B 0.07、D1 0.10、D2 0.10、D5 0.12。

「目立つ出来事」は、超大陸と小さな隕石を除いた出来事（生命の誕生、大酸化、複雑化、陸上進出、全球凍結、大きな隕石、大量絶滅など）。

問いへの答え:

- 生き続けることはできる。1号の時間を細かくすれば、主役の惑星は5年以上生きる（D1、D2）。いまの本番は約200日で全滅する。
- ただ、いまの出来事の種類のままだと、1日あたりの目立つ出来事はほぼ0になる。いまの出来事（大量絶滅、大きな隕石、全球凍結）は数億年の時間向けで、100万年単位ではまず起きない。
- 細かい時間での変化の主役は、系統の誕生と絶滅（1日1.5から7）になる。驚きを保つには、系統の変化を見せる図鑑と系統樹と、細かい時間の出来事（氷期と間氷期、小さな隕石の影響、生息域の移動など）が要る。
- 青白い恒星はそれでも明るくなり続け、D2 でも5年で20%の未来が全滅する。長い目で見れば、恒星の寿命と、次の星への引き継ぎも要る。
- #263 までの歴史を残せるのは D（号番号で切り替える）。A と B は過去の歴史も変わる（A では #231 の巨大な隕石で全滅し、#263 では生き物がいない。B では多細胞が #168 まで遅れる）。D の切り替えには、世界の中の理由がない（なぜ #264 から時間が遅くなるのか）。

気づいたこと:

- 時間を細かくすると「考える生き物」が現れる未来が増える（D2、D5 で25%）。大型の生き物の時代が長くなるため。
