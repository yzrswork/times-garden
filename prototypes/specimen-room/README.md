# 試作 01: 生物標本室

## 確かめる問い

号の種と惑星環境（重力、恒星、生息域、大気）から生き物を決定論的に生成したとき、環境ごとの理由がついた「ロマンのある生き物」になるか。ただの塊にならないか。

## 動かし方

`index.html` をブラウザで開く。外部ライブラリは使わない（フォントのみ Google Fonts）。

- 号と記事キーワードを入れ、重力・恒星・生息域・大気を選ぶと、生き物が生成されて動く。
- 「次の個体」「惑星ごと引き直す」「伝説級が出るまで引く」で引き直せる。
- 下段に同じ号・同じ惑星の8体が並ぶ（属名は記事キーワードで共通、種名と体は個体ごと）。

## 状態

終了（2026-11-05）。Claude Artifact として公開したものの保存版。

## 結果

- 体の型は5種類（体節型、傘型、放射腕、胞子型、不定形）。81通りの環境で各3体を生成し、5種類すべてが出てエラーなし（Playwright）。
- 図鑑カードに「なぜこの形か」を環境の理由として出せた（高重力で低く平たい、赤色矮星で黒く目が大きい、など）。
- Owner の感想: 「気持ち悪いのばっかりで最高」。
- この感想から、時代が進むと収斂進化で見慣れた形に寄っていく構想、さらに惑星と生き物が互いを変え合う生態系の構想へ発展した。
- 判定: 5つの質問による振り返りは未実施のため未記録。
- 本番では、親から子へ遺伝子を受け継ぐ方式で書き直す（この試作は毎回ゼロから生成する）。
