# 試作 02: 観測窓

## 確かめる問い

同じ架空の惑星を、神の視点と生き物の視点（見え方の種類ごと）で眺めたとき、視点を変えるだけで別の世界に見えるか。静的 HTML でどこまで見た目を上げられるか。

## 動かし方

`index.html` をブラウザで開く。地表と生き物の目は three.js r128（cdnjs から読み込み）を使う。

- 4段階の視点: 恒星系、惑星、地表（神の視点）、生き物の目。タブか数字キー 1〜4 で切り替える。
- 地表: ドラッグで回転、ホイールで拡大縮小。地形、気温、酸素、生き物の分布を重ねて切り替える。
- 生き物の目: ふつうの目、暗視、目のない種、複眼を切り替える。神の視点と同じ地形の上を歩く。
- 「別の号」で別の惑星が生まれる。

## 状態

終了（2026-11-06）。Claude Artifact として公開したものの保存版（第3版）。

## 結果

### 振り返り（Owner、2026-11-06）

1. 問いの答えは出たか: 出た。
2. 一番良かった瞬間: 視点の違い。神の視点の拡大・縮小。
3. 一番だめだった瞬間: 生き物のキャラクターの描画がしょぼい。
4. 予想外だったこと: 特になし。
5. 判定: 進める。

### わかったこと

- 2D Canvas の地表と生き物の目は「スーファミ品質」という評価だったため、three.js の 3D に作り直した。光と影、霧、揺れる草と植物、歩く生き物、見え方ごとの画面効果（暗視、点群、複眼）まで静的 HTML で出せた。
- 目のない種は、点を画面に重ねる方式だと視点が動いたときに点が流れて筋になった。点を地形や物体の上に固定して残す方式に変えて解消した。
- 複眼は、世界を1回描いた画像をレンズごとに切り出す方式なので、目の数を増やしても重くならない。
- 確認: GPU なしのソフトウェア描画環境で全視点を撮影し、エラーなし。実機の GPU での滑らかさとスマホでの動作は未確認。
