# 試作 03: 3D 標本室

## 確かめる問い

試作 01 の遺伝子と環境の縛りをそのまま使い、描画だけを 3D にしたとき、試作 02 の振り返りで挙がった「生き物のキャラクター描画がしょぼい」が解消されるか。

## 動かし方

`index.html` をブラウザで開く。three.js r128（cdnjs から読み込み）を使う。

- 操作は試作 01 と同じ（号、記事キーワード、重力、恒星、生息域、大気、次の個体、惑星ごと引き直す、伝説級が出るまで引く）。
- ドラッグで回転、ホイールで拡大縮小。下段で同じ号・同じ惑星の8体を切り替える。

## 状態

終了（2026-11-06）。Claude Artifact として公開したものの保存版。

## 結果

- 体は楕円体をなめらかに溶け合わせた距離場から Surface Nets でメッシュ化し、継ぎ目のない1つの形にした。体の型5種類（体節型、傘型、放射腕、胞子型、不定形）すべてで生成でき、1体の生成は 15〜100ms（ソフトウェア描画環境）。
- 質感: 背中は暗くお腹は明るい陰影、遺伝子の模様、縁がうっすら透けて光るリム処理。青白い恒星の種は半透明。
- 動き: 関節で歩く脚、ゆらぐ触手や糸、羽ばたくひれ、体のうねり、脈打つ傘、波打つ表面。目はカメラを追い、まばたきする。
- 環境パーツ（殻、結晶の棘、繊毛、発光点）と伝説級の演出（光の輪、星屑の尾、全身の目）も 3D にした。
- 光の反射用の環境マップ（PMREM）を入れると、ソフトウェア描画環境で画面全体が黒くなった。外して照明を増やした。実機 GPU では未確認。
- Owner の感想: 「いいと思う」。
- 判定: 5つの質問による振り返りは未実施のため未記録。
