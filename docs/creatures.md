# 生き物と文明の設計

状態: 設計は 2026-11-19 にひととおり固まった。実装は下の「実装の段階」の順に、Owner と相談しながら進める。具体的な数値は、実装のときに長期運転テストで決める（下の「調整で決める数値」）。

## ねらい

いまの生き物は SF に寄っている。それはそれで残しつつ、長い時間をかけて、条件がそろったときにだけ「知っている形」に出会える世代を作る。何週間も覗いているうちに「この系統、魚っぽくなってきたな」と気づく、じわじわくる感じを目指す。その先には文明があり、何が出るかわからない。

## 確定事項（2026-11-19 Owner OK）

1. ふだん出る「知っている形」は、「似ているけどちょっと違う」を基本にする。本当にそっくりなのは伝説級だけ。
2. グレイ型は、人間っぽい型の先（長い時間の果て）に置く。
3. ペースの手応え: 「〇〇っぽい」は数週間、「そっくり」は数か月から年単位。
4. 図鑑では、姿と短い一言で見せる。似ている度合いを数字では出さない。
5. 計算にない環境の値を足す。重力と大気の濃さは、惑星ごとに種から1回決める。海の深さは、系統ごとの見た目の性質として親から受け継ぐ。どれも気候や個体数の計算には使わない（これまでの歴史を変えない）。
6. 型の一覧に、翼のある型と、植物のような生き物を足す。
7. 原始の時代の SF っぽい形の描き方の改善（輪郭線、顔、体の比率）は、型の話が固まってから行う（固まったので、実装の段階1で行う）。
8. 惑星はおよそ1年で切り替わる。
9. 図鑑は肥大化させない。
10. 名前は記事とキーワードから作る。
11. 文明まで描く。何が出るかわからないガチャの楽しさを大事にする。
12. 生き物の目で見る視点と型の対応は、Claude に一任。
13. 残っていた設計（1年の中の時間の配分、惑星の最期と引き継ぎ、文明の段階、型の条件、化石の線、ガチャの回数）は、Claude のおすすめで決める。この文書の各節がその中身。

## 惑星の1年

確定事項8。1つの惑星を、およそ1年（1日2号で約730号）観測する。

- 2026-11-18 の確定事項「主役は創刊号から続く1つの惑星の連続した歴史」は、「1年ごとに次の惑星へ続く、1つの宇宙の連続した歴史」に広がる。1つの惑星の中では、これまでどおり途切れずに続く。
- 1年の区切りは「観測所が次の星へ移る」こととして描く。惑星が死ぬとは限らない。赤色矮星のように数兆年も輝く恒星でも、1年で観測は次へ移る（柱4: 恒星の寿命を1年に合わせて曲げない）。

### 時間の配分

時代ごとに、1号の時間を変える。号数の目安は、長期運転テストで中央値が近くなるように合わせる。ばらつきは残す（早く文明が来る星も、文明が来ない星もある）。

| 時代 | 号数の目安 | 1号の時間の目安 | 驚きの中心 |
|---|---|---|---|
| 誕生（恒星、惑星、最初の生命） | 約1割（約70号） | 数百万年 | 星と海の誕生、最初の生命 |
| 単純な生命（生命から多細胞まで） | 約2割（約150号） | 約1000万年 | 大酸化、全球凍結、真核生物 |
| 形の時代（多細胞から考える生き物まで） | 約4から5割（約330号） | 数百万年 | 系統の誕生と絶滅、「知っている形」への寄り |
| 文明（考える生き物から観測の終わりまで） | 約2から3割（約180号） | 数千年（進化の計算はほぼ止まる） | 文明の段階、住まいと町の姿 |

- 文明は数千年で姿を変えるが、進化は数百万年かかる。文明の時代は進化と気候の計算をほぼ止め、文明の段階の計算で進める。
- 考える生き物が現れない惑星では、形の時代が観測の終わりまで続く。
- 誕生の時代は、いまの計算にない（いまの計算は、惑星ができたところから始まる）。恒星と惑星の誕生を短い出来事として足す（handover の「ガス雲、恒星、惑星系、惑星環境、生命、進化」）。

### いまの主役の惑星

- いまの計算（1号2000万年）のままだと、創刊（2026-07-10）から1年たたない2027年6月ごろに、灼熱になって海が蒸発し、全滅する見込み（試作06の試算）。
- 時間の配分を入れたら、その号から先だけを新しい配分で進める（それまでの歴史は変えない）。主役の惑星はすでに形の時代にいる（#165 から大型の生き物）。
- 主役の惑星の観測は、遅くとも創刊1周年（2027-07-10 ごろ、#730 前後）で終える。

## 惑星の最期と引き継ぎ

### 観測の終わり方

終わり方もガチャにする。1年の区切りより前に、自然に終わることもある。

| 終わり方 | 起きる条件 | 珍しさ |
|---|---|---|
| 観測を終えて次の星へ | 1年の区切りまで生き物が続いた | よくある |
| 灼熱の星 | 恒星が明るくなり、海が蒸発した | よくある |
| 死の星 | 生き物が全滅し、1か月（約60号）たっても戻らない | よくある |
| 凍りついた星 | 全球凍結が長く続き、生き物が絶えた | 珍しい |
| 巨大な隕石 | 巨大な隕石で、生き物が戻らないほど壊れた | 珍しい |
| 文明が星を出る | 文明が未来都市の段階まで進んだ | 伝説級 |

- 自然に終わった星は、1か月ほどの「静かな星」の観測を残してから次へ移る（全滅のあとに生命がふたたび生まれることもあるので、すぐには切り替えない）。

### 次の星へ引き継ぐもの

- 宇宙の図鑑: その星の図鑑（生きていた系統と化石）は、星ごとの巻として残る。
- 宇宙の年表: 「1つ目の星: 青白い恒星、#1 から #730」のように、観測した星を年表に並べる。
- 文明が星を出たときだけ、次の星で、その文明の遺跡や探査機が見つかることがある（伝説級）。星どうしがつながる。
- 次の星は、切り替わる号の内容を種にして決める（恒星、重力、大気など）。決定論は保つ。

## 土台: 収斂進化

別々の系統が、同じ環境の圧力で同じ形にたどり着くこと。これを使うと、「知っている形が出てくる」ことに理由が付く（柱1、柱4）。

| 地球で起きたこと | 出典 | 状態 |
|---|---|---|
| サメ（魚）、魚竜（爬虫類）、イルカ（哺乳類）が、別々に同じ流線形になった | 教科書的な例 | 合意 |
| 甲殻類の中で、カニ型の体が少なくとも5回、別々に生まれた（カニ化） | Keiler ほか 2017 | 合意 |
| 目は、生き物の歴史の中で何十回も別々に生まれた | Salvini-Plawen と Mayr 1977（40から65回の見積もり） | 合意（回数は見積もり） |
| 飛ぶ力は、昆虫、翼竜、鳥、コウモリで別々に生まれた | 教科書的な例 | 合意 |
| 石炭紀の巨大な昆虫は、酸素が濃かったから大きくなれた | 酸素と体の大きさの関係の研究 | 論争 |
| 知性を持つ生き物は、別の系統からでも人に似た形になりうる | Conway Morris の収斂の議論、Russell と Séguin 1982 のダイノサウロイド | 思弁 |

## 世代の流れ

1. 原始の時代: 不定形、クラゲ、群体。いまの SF っぽい生き物（試作01、03）はここ。
2. 寄っていく時代: 同じ環境に長くいる系統ほど、形が少しずつ「知っている形」に寄る。ただ、目の数や関節の向き、色などの系統由来のずれが残り、「魚っぽいけど目が3つ」のような、知っているのにちょっと違う姿になる。
3. 奇跡の時代: 条件がすべてそろった系統だけ、ずれまで消えて「地球の〇〇にそっくり」になる。伝説級。

## 系統の見た目の性質

系統ごとに持ち、親から子へ受け継ぐ。分岐のたびに少しだけ変わる。気候や個体数の計算には使わない（確定事項5）。

- 体の型: 原始の5種類（体節型、傘型、放射腕、胞子型、不定形。試作01）から始まる。
- 体の大きさ: 計算の複雑さ（1から5）と、陸の酸素（濃いほど大きくなれる）で決まる。
- 目: 数、大きさ、種類（レンズの目、複眼、なし）。
- 体の覆い: 殻、うろこ、毛、むき出し。
- 動く部分: ひれ、脚（本数）、翼、触手、なし。
- 住む深さ: 浅い、中ほど、深い（海の系統だけ）。
- 色と模様: 計算の体の色（アルベド）を明るさに使い、恒星の色で全体の色味が決まる（アートバイブル）。
- 系統由来のずれ: 目の数、関節の向き、左右の非対称など。型に寄っても残る。

惑星ごとに、重力と大気の濃さを種から1回決める（確定事項5）。

## 型と、そこへ寄る条件

条件は、計算にある値（恒星、気温、酸素、海か陸か、複雑さ、光合成、好む温度、体の色）と、足す値（重力、大気の濃さ、住む深さ）で決める。条件に合うほど、分岐のたびにその型へ少しずつ寄る。

| 型 | 寄る条件 | 地球の根拠 |
|---|---|---|
| 魚型 | 海、浅いから中ほど、複雑さ4以上（大型）、系統が多い（捕食が多い） | 流線形の収斂（合意） |
| 深海魚型 | 海、深い、または赤色矮星（光が少ない）、複雑さ3以上。光る器官、大きな口と目 | 深海の暗さへの適応（合意） |
| カニ型（甲殻類） | 海の浅いところ、体節型、殻、複雑さ3以上 | カニ化（合意） |
| 昆虫型 | 陸、体節型、小型。陸の酸素が濃いほど大きくなれる | 石炭紀の巨大昆虫（論争） |
| 爬虫類型 | 陸、複雑さ4以上、好む温度が高い（暑い）、うろこ | 変温と乾燥への適応（合意） |
| 獣型 | 陸、複雑さ4以上、好む温度が低い（寒い）、毛 | 恒温と毛（合意） |
| 翼のある型 | 陸、複雑さ3以上、大気が濃いか重力が弱い | 飛ぶ力の収斂（合意） |
| 植物のような生き物 | 光合成をする系統、陸か浅い海。動かなくなり、日を受ける面を広げる | 地球の植物（合意）。取り込んだ葉緑体で光合成をするウミウシもいる（いることは合意、どこまで頼るかは論争） |
| 人間っぽい型 | 考える生き物（複雑さ5）、陸。二足歩行と器用な手 | ダイノサウロイド（思弁） |
| グレイ型 | 人間っぽい型の系統が、考える生き物になってから長い時間がたった。頭が大きく体が細い。暗い恒星の下なら目もさらに大きい | 地球の人たちが想像した「宇宙人」（遊び。思弁） |

### 「そっくり」になる条件（伝説級）

- 型の条件がすべてそろい、長い時間（数か月以上）その型にとどまった系統だけ、系統由来のずれが消える。
- さらに、惑星の条件が地球に近いこと（黄色い恒星、重力と大気がふつう）を求める。「地球に似た星でだけ、地球の生き物にそっくりな種が生まれる」ことに理由が付く（柱1）。条件がすべて地球と一致した星が「地球」として現れる、handover の伝説級ともつながる。

主役の惑星の酸素は、#264 の時点でいまの地球の1.6倍あり、地球の石炭紀くらいの濃さ。昆虫型が大きく育つ下地はすでにある。ただ、恒星が青白いので「そっくり」にはならない。

## 似ていく仕組みとペース

- 寄る速さは、確定事項3のペース（「っぽい」は数週間、「そっくり」は数か月から年）になるように決める。形の時代の1号は数百万年なので、「っぽい」（約30から60号）までが1億年から数億年ほど、「そっくり」（数百号）までが数億年から10億年ほどになる。地球で収斂に数千万年から数億年かかったのと、おおむね同じ桁。
- まずは見た目の層として足し、気候や個体数の計算には影響させない。いまの歴史を変えずに足せる。形が生態に効く（殻があると隕石に強い、など）のは、その次の段階。

## 文明

確定事項11。考える生き物の系統は、文明を持つことがある。

### 段階

| 段階 | 姿 | 次へ進む条件 |
|---|---|---|
| 1. 痕跡 | 火、道具、石の並び | 考える生き物が現れてしばらくたつ |
| 2. 集落 | 住まいの種類が決まる（下の表） | 時間と記事 |
| 3. 町 | 石や、その種類なりの材料の町 | 時間と記事 |
| 4. 都市 | ビルの街（種類なりの姿） | 時間と、技術の記事 |
| 5. 未来都市 | サイバーパンクの都市（種類なりの姿） | 長い時間と、技術の記事が多い号 |

- 段階は、時間と記事で進む。技術やプログラミングの記事が多い号を経た文明ほど、速く進む（Times とのつながり）。
- どの段階でも、滅びることがある（大きな隕石、気候の急変、理由のわからない消滅）。滅びた文明は、遺跡として図鑑と生き物の視点に残る。戦争を直接描くことはしない。
- 未来都市まで進んだ文明は、まれに星を出る（伝説級。惑星の最期と引き継ぎ）。

### 住まいの種類（集落の段階で決まり、その先も受け継ぐ）

| 住まい | 出る理由 | 珍しさ |
|---|---|---|
| 土の家 | 乾いた平地 | よくある |
| 崖の住まい | 山が多い、外敵が多い、翼のある型 | よくある |
| 地下の町 | 暑すぎるか寒すぎる気候 | 珍しい |
| 水中の町 | 水中で暮らす型（魚人のような型） | 珍しい |
| 木や植物の町 | 植物のような生き物が多い星 | 珍しい |
| 高い塔の町 | 重力が弱い | 珍しい |

- 住まいの種類は、その先の段階の姿にも残る。崖の文明はやがて崖の巨大都市に、水中の文明は水中のドーム都市になる。同じ「サイバーパンクの都市」でも星ごとに違う姿になり、ガチャの幅が広がる。
- 街づくりはしない。プレイヤーは見るだけ（柱の「やらないこと」: 共有の世界を直接いじらない）。最初の構想「街づくりx人工生命」とは、作るのではなく観測する点で違う。
- ここでの「ガチャ」は、何が出るかわからない楽しさのこと。プレイヤーが回したり、報酬や通知で呼び戻したりはしない（柱の「やらないこと」: 毎日ログインさせる仕組み）。

## ガチャの回数と珍しさ

主役の惑星は1年に1つなので、それだけだと伝説級に出会えない。2026-11-18 の確定事項「号ごとの惑星は、同じ宇宙の別の星として図鑑に並べるおまけ」を、ガチャの回数として使う。

- 毎号の別の星（年に約730個）: その号の内容を種にして、星の1年ぶんの歴史を一気に計算し、要約（恒星、目立つ系統の姿、文明の到達段階、終わり方）だけを図鑑に並べる。重い計算は GitHub Actions で行う。
- 主役の惑星: 1年かけて、じわじわ観測する。図鑑と系統樹と生き物の視点で深く見られるのは主役の惑星だけ。

珍しさの目安（別の星1つあたり。調整で決める）:

| 珍しさ | 出会う割合 | 1年に出会う数の目安 | 例 |
|---|---|---|---|
| よくある | 残り | たくさん | 「っぽい」形、土や崖の集落 |
| 珍しい | 約1割 | 数十 | 都市まで進んだ文明、水中の町、凍りついた星 |
| 伝説級 | 約1% | 数個 | 地球の生き物にそっくりな種、グレイ型、サイバーパンクの都市、文明が星を出る |
| 伝説級の中でもまれ | 約0.1% | 1年に1つあるかないか | 「地球」そのもの |

## 図鑑

- 載せる範囲（確定事項9）: いま生きている系統は全部載せる。絶滅した系統は、50号以上続いたものと、節目になったもの（初めて陸に上がった、初めて考える生き物になった、型に寄った、など）だけを化石として載せる。ほかは系統樹の枝として見えるだけ。参考: 主役の惑星では #264 までに約2,800の系統が生まれ、50号以上続いたのは62、いま生きているのは48。
- 名前（確定事項10）: 属名は、祖先の系統が生まれた号の記事キーワードから作る。種名は、その系統が分かれた号の記事キーワードから作る。発見した号ときっかけの記事を図鑑に残す。名前をたどれば、どの号のどの記事から生まれたかがわかる。
- 一言（確定事項4）の例:
  - 「地球の魚に少し似てきた」
  - 「目が3つあることを除けば、カニにそっくり」
  - 「地球の人たちが想像した『宇宙人』にそっくり」
- 伝説級には、「地球ではこうだった」の短い解説カードを添える（柱4）。

## 生き物の目で見る視点

確定事項12（Claude の案）。試作02の4つの見え方を、系統の目の性質から決める。形の変化が、そのまま生き物の視点の体験の違いになる（柱2）。

- 目がない系統: 点群と音の波紋。深海や洞窟で目を失った系統など。
- 複眼の系統: 画面を分割する見え方。昆虫型とカニ型の多く。
- 大きな目で、暗い環境（暗い恒星、深い海）に住む系統: 暗視。深海魚型、グレイ型。
- それ以外: ふつうの見え方。魚型、爬虫類型、獣型、人間っぽい型など。
- 系統由来のずれ（目が3つの魚など）は、見え方の種類は変えず、視野の広さや色味の違いとして出す。
- 文明のある星では、生き物の視点で町を歩ける。

## 柱との関係

- 柱1（偶然なのに出来すぎている）: 形にも住まいにも、たどれる理由（環境、系統、記事）がある。そっくりは地球に近い星の伝説級だけなので、まれさを保てる。
- 柱2（二つの視点）: 型と目の性質で、生き物の視点の見え方が変わる。文明は神の視点では町の明かりとして、生き物の視点では歩ける町として見える。
- 柱3（覗くたびに驚きがある）: 形の変化と文明の段階がじわじわ進む。毎号の別の星で、何が出るかわからない。
- 柱4（本物の知識に根ざす）: 収斂進化という実際の現象に基づき、地球の例と見比べられる。恒星の寿命を1年に合わせて曲げない。
- やらないことには当たらない。プレイヤーは見るだけで、地球は固定の舞台ではなく、まれに現れる一致として扱う。

## 実装の段階（案）

一気に作らず、段階ごとに Owner と確かめながら進める。1と2は、これまでの歴史を変えない。

1. 見た目の層: 系統の見た目の性質と受け継ぎ、惑星の重力と大気、原始の形の描き方の改善（輪郭線、顔、体の比率）、いま生きている系統の図鑑（姿と名前）。
   - 2026-11-19 着手。`engine/traits.mjs`（`eco-2`）で、系統の見た目の性質と受け継ぎ、惑星の重力と大気、図鑑の姿（文章）まで入れた。1号ごとの記録は `eco-1` とビット単位で同じ（`tests/traits.test.mjs` が固定）。
   - 残り: 図鑑の名前（記事キーワードが要る。台帳はいまキーワードの語そのものを持っていない）、原始の形の描き方の改善（絵を描く先が要る。見る画面は段階6）。
2. 収斂: 型へ寄る仕組み、図鑑の一言、化石、系統樹。
3. 惑星の1年: 時間の配分、誕生の時代、観測の終わり方と次の星への切り替え。計算が変わるので `SIM_VERSION` を上げる。主役の惑星が最期を迎える2027年6月ごろより前に入れる。
4. 文明: 段階、住まいの種類、遺跡。
5. 毎号の別の星: ガチャの回数。
6. 見る画面: 神の視点と生き物の視点（試作02の書き直し）。1から並行して少しずつ。

## 調整で決める数値

実装のときに、長期運転テストで決めて定数に置く（意味、単位、出典、状態付き）。

- 時代ごとの1号の時間（号数の目安に合わせる）。
- 型へ寄る速さと、「そっくり」になる確率（ペースの手応えに合わせる）。
- 文明の段階が進む確率と、滅びる確率。
- 珍しさの割合（上の表の目安に合わせる）。
- 死の星と判断するまでの号数（目安は約60号）。
- 化石として載せる「長く続いた」の線（目安は50号）。
