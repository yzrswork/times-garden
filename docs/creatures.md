## ねらい

いまの生き物は SF に寄っている。それはそれで残しつつ、長い時間をかけて、条件がそろったときにだけ「知っている形」に出会える世代を作る。何週間も覗いているうちに「この系統、魚っぽくなってきたな」と気づく、じわじわくる感じを目指す。

## 確定事項（2026-11-19 Owner OK）

1. ふだん出る「知っている形」は、「似ているけどちょっと違う」を基本にする。本当にそっくりなのは伝説級だけ。
2. グレイ型は、人間っぽい型の先（長い時間の果て）に置く。
3. ペースの手応え: 「〇〇っぽい」は数週間、「そっくり」は数か月から年単位。
4. 図鑑では、姿と短い一言で見せる。似ている度合いを数字では出さない。
5. 計算にない環境の値を足す。重力と大気の濃さは、惑星ごとに種から1回決める。海の深さは、系統ごとの見た目の性質として親から受け継ぐ。どれも気候や個体数の計算には使わない（これまでの歴史を変えない）。
6. 型の一覧に、翼のある型（大気が濃い、重力が弱いと飛びやすい）と、植物のような生き物（光合成をする系統が動かなくなっていく）を足す。
7. 原始の時代の SF っぽい形の描き方の改善（輪郭線、顔、体の比率）は、型の話が固まってから行う。
8. 惑星はおよそ1年で切り替わる（下の「惑星の1年」）。
9. 図鑑は肥大化させない。いま生きている系統は全部載せ、絶滅した系統は、長く続いたものと節目になったもの（初めて陸に上がった、など）だけを化石として載せる。ほかは系統樹の枝として見えるだけにする。
10. 名前は記事とキーワードから作る。属名は祖先の系統が生まれた号の記事キーワードから、種名はその系統が分かれた号から。発見した号ときっかけの記事を図鑑に残す。
11. 文明まで描く。何が出るかわからないガチャの楽しさを大事にする（下の「文明」）。
12. 生き物の目で見る視点と型の対応は、Claude に一任（下の「生き物の目で見る視点」）。

## 惑星の1年

- 1つの惑星の誕生から最期までを、およそ1年（1日2号で約730号）で描く。最期のあと、同じ宇宙の次の惑星へ切り替わる。
- 2026-11-18 の確定事項「主役は創刊号から続く1つの惑星の連続した歴史」は、「1年ごとに次の惑星へ続く、1つの宇宙の連続した歴史」に広がる。1つの惑星の中では、これまでどおり途切れずに続く。
- 1年の中の時間の配分を、時代で変える。深い時間（星と惑星の誕生、最初の生命）は速く進め、生き物が形を変える時代と文明の時代はゆっくり進める。試作06で、時間を細かくすると惑星は長く生きるが、いまの出来事（大量絶滅、全球凍結など）は減ることがわかっている。ゆっくりの時代には、形の変化と文明を驚きの中心に置く。
- いまの主役の惑星は、このままでも、創刊（2026-07-10）から1年たたない2027年6月ごろに最期を迎える見込み（試作06の試算。灼熱になり海が蒸発する）。

## 土台: 収斂進化

別々の系統が、同じ環境の圧力で同じ形にたどり着くこと。これを使うと、「知っている形が出てくる」ことに理由が付く（柱1、柱4）。

| 地球で起きたこと | 出典 | 状態 |
|---|---|---|
| サメ（魚）、魚竜（爬虫類）、イルカ（哺乳類）が、別々に同じ流線形になった | 教科書的な例 | 合意 |
| 甲殻類の中で、カニ型の体が少なくとも5回、別々に生まれた（カニ化） | Keiler ほか 2017 | 合意 |
| 目は、生き物の歴史の中で何十回も別々に生まれた | Salvini-Plawen と Mayr 1977（40から65回の見積もり） | 合意（回数は見積もり） |
| 石炭紀の巨大な昆虫は、酸素が濃かったから大きくなれた | 酸素と体の大きさの関係の研究 | 論争 |
| 知性を持つ生き物は、別の系統からでも人に似た形になりうる | Conway Morris の収斂の議論、Russell と Séguin 1982 のダイノサウロイド | 思弁 |

## 世代の流れ

1. 原始の時代: 不定形、クラゲ、群体。いまの SF っぽい生き物（試作01、03）はここ。
2. 寄っていく時代: 同じ環境に長くいる系統ほど、形が少しずつ「知っている形」に寄る。ただ、目の数や関節の向き、色などの系統由来のずれが残り、「魚っぽいけど目が3つ」のような、知っているのにちょっと違う姿になる。
3. 奇跡の時代: 条件がすべてそろった系統だけ、ずれまで消えて「地球の〇〇にそっくり」になる。伝説級。

## 型と、そこへ寄る条件（案）

| 型 | 寄る条件 | 地球の根拠 |
|---|---|---|
| 魚型 | 海、大型、速く泳ぐ必要がある（捕食が多い） | 流線形の収斂（合意） |
| 深海魚型 | 深い海や暗い恒星で、光が少ない。光る器官、大きな口と目 | 深海の暗さへの適応（合意） |
| カニ型（甲殻類） | 浅い海から岸、硬い殻を持つ体節型の系統 | カニ化（合意） |
| 昆虫型 | 陸、小型の体節型。酸素が濃いほど大きくなれる | 石炭紀の巨大昆虫（論争） |
| 爬虫類型 | 陸、4本脚、暑く乾いた気候 | 変温と乾燥への適応（合意） |
| 獣型 | 陸、寒い気候、体温を保つ毛 | 恒温と毛（合意） |
| 人間っぽい型 | 考える生き物、陸、長い時間。二足歩行と器用な手 | ダイノサウロイド（思弁） |
| グレイ型 | 人間っぽい型の系統が、さらに長い時間をかけて頭が大きく体が細くなった姿。暗い恒星の下なら目もさらに大きい | 地球の人たちが想像した「宇宙人」（遊び。思弁） |
| 翼のある型 | 陸、大気が濃い、重力が弱い。飛びやすい条件 | 飛ぶ力は昆虫、翼竜、鳥、コウモリで別々に生まれた（合意） |
| 植物のような生き物 | 光合成をする系統が、動かなくなり、日を受ける面を広げていく | 地球の植物（合意）。取り込んだ葉緑体で光合成をするウミウシもいる（いることは合意、どこまで頼るかは論争） |

主役の惑星の酸素は、#264 の時点でいまの地球の1.6倍あり、地球の石炭紀くらいの濃さ。昆虫型が大きく育つ下地はすでにある。

## 似ていく仕組み（案）

- 形は系統ごとに持ち、親から子へ受け継ぐ。分岐のたびに少しだけ変わる。
- 環境の圧力で、条件に合う型へ少しずつ寄る。寄る速さは定数で持ち、確定事項3のペースに合わせて決める。
- 系統由来のずれは、寄っても残る。ずれまで消えるのは、条件がすべてそろったとき（伝説級）。
- まずは見た目の層として足し、気候や個体数の計算には影響させない。いまの歴史を変えずに足せる。形が生態に効く（殻があると隕石に強い、など）のは次の段階。

## 図鑑の一言（例）

- 「地球の魚に少し似てきた」
- 「目が3つあることを除けば、カニにそっくり」
- 「地球の人たちが想像した『宇宙人』にそっくり」
- 伝説級には、「地球ではこうだった」の短い解説カードを添える（柱4）。

## 文明

確定事項11。考える生き物の系統は、文明を持つことがある。住まいと町の姿は、系統の体と環境と時間と記事から決まり、何が出るかわからない。

- 姿の例: 土でできた家、崖に掘った住まい、水中の町（魚人のような型）、石の町、ビルの街、サイバーパンクの都市。
- 出かたの理由（案）:
  - 体: 水中で暮らす型なら水中の町、翼のある型なら高い崖や塔。
  - 環境: 乾いた平地なら土、山が多いか外敵が多いなら崖、重力が弱ければ高い建物が建ちやすい。
  - 時間: 長く続いた文明ほど、技術の進んだ姿になる。
  - 記事: 技術の記事が多い号を経た文明は、ビルやサイバーパンクに寄りやすい（Times とのつながり）。
- 珍しさ（案）: 土や崖はよくある、石の町やビルは珍しい、サイバーパンクの都市は伝説級。
- 街づくりはしない。プレイヤーは見るだけ（柱の「やらないこと」: 共有の世界を直接いじらない）。最初の構想「街づくりx人工生命」とは、作るのではなく観測する点で違う。

## 生き物の目で見る視点

確定事項12（Claude の案）。試作02の4つの見え方を、系統の目の性質から決める。形の変化が、そのまま生き物の視点の体験の違いになる（柱2）。

- 目の性質は、系統の見た目の性質として親から受け継ぐ（数、大きさ、種類）。
- 目がない系統: 点群と音の波紋。深海や洞窟で目を失った系統など。
- 複眼の系統: 画面を分割する見え方。昆虫型とカニ型の多く。
- 大きな目で、暗い環境（暗い恒星、深い海）に住む系統: 暗視。深海魚型、グレイ型。
- それ以外: ふつうの見え方。魚型、爬虫類型、獣型、人間っぽい型など。
- 系統由来のずれ（目が3つの魚など）は、見え方の種類は変えず、視野の広さや色味の違いとして出す。

## 柱との関係

- 柱1（偶然なのに出来すぎている）: 形にたどれる理由（環境、系統）がある。そっくりは伝説級だけなので、まれさを保てる。
- 柱3（覗くたびに驚きがある）: 形の変化がじわじわ進み、覗くたびに少し違う。
- 柱4（本物の知識に根ざす）: 収斂進化という実際の現象に基づき、地球の例と見比べられる。
- 文明は柱1と柱3を強める。住まいや町の姿に体と環境の理由があり、何が出るかわからない。
- やらないこと（実在の地球を固定の舞台にする）には当たらない。地球の生き物に似るのは、架空の惑星でまれに起きる一致として扱う。

## まだ決めていないこと

- 型の条件を、計算にある値（恒星、気温、酸素、海か陸か、複雑さ、光合成、好む温度、体の色）と、足す値（重力、大気の濃さ、海の深さ）でどう表すか。
- 惑星の1年の中の、時代ごとの時間の配分（試作06の結果を使う）。
- 惑星の最期の形（恒星の寿命、全滅、文明が星を出る、など）と、次の惑星へ何を引き継ぐか（図鑑、化石、伝説など）。
- 文明の段階と、住まいや町の種類ごとの出かたの条件と珍しさ。
- 原始の時代の SF っぽい形の描き方の改善（確定事項7のとおり後で）。2026-11-19 に試作01と03を撮影して見た弱いところ: 形が単純で頭と胴の区別がない、脚が細く短い、目が見どころになっていない、3D に輪郭線がない、クラゲが地球のクラゲに似すぎている、姿が計算の系統とつながっていない。
- 化石として載せる「長く続いた」の線（例: 50号以上）。参考: 主役の惑星では #264 までに約2,800の系統が生まれた（号の終わりまで残ったのは612、10号以上続いたのは296、50号以上は62、いま生きているのは48）。
