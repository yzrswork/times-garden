# Times Garden の柱

設計で迷ったときは、この表で判定する。新しい機能や演出は、少なくとも1本の柱を強め、どの柱も弱めず、「やらないこと」に当たらないときだけ採用する。

## 一言で

YZRS Times の号が出るたびに進む、架空の宇宙と惑星と生き物の歴史を、神の視点と生き物の視点の両方からたどり直す観測ゲーム。

## 柱

### 1. 偶然なのに出来すぎている

世界は種と単純なルールだけで決まるのに、結果がまるで設計されたように見える瞬間がある。

- 判定の問い: その出来事や形に、たどれる理由（環境、系統、前の時代の事件）があるか。理由のない純粋なランダムは不採用。
- 判定の問い: 「出来すぎた一致」はまれか。頻発すると驚きが消える。

### 2. 二つの視点でたどり直す

神の視点では歴史と数値の全体を知り、生き物の視点ではその一生ぶんの感覚だけで世界を見る。両者を行き来すると、同じ出来事が違って見える。

- 判定の問い: その機能は、どちらかの視点の体験を深めるか。両方の視点で同じことしかしない機能は優先度を下げる。
- 判定の問い: 生き物の視点で、その体（目の有無、数、環境）に応じた見え方の違いが出るか。

### 3. 覗くたびに驚きがある

普段は見ず、気になったときに開くゲーム。開いた時点で、前回から何が起きたかがすぐにわかり、「こうなったのか」と思える。

- 判定の問い: 久しぶりに開いた人が、進んだ号ぶんの変化を一目でつかめるか。
- 判定の問い: 長期運転テストで、毎回同じ結末（全滅、一種独占、停滞）に偏っていないか。

### 4. 本物の知識に根ざす

ルールと数値は現実の宇宙、地球、進化の研究に由来し、遊ぶうちに知識がつく。

- 判定の問い: その数値やルールに出典と状態（合意、論争、思弁）が付いているか。
- 判定の問い: 現実と見比べられる解説を添えられるか。

## やらないこと

- プレイヤーが共有の世界を直接いじること。全員が同じ号で同じ世界を見る前提を守る。試したい変更は、手元だけで再計算する「もしも分岐」で扱う。
- 写実を目指すこと。統一感のあるスタイライズで見せる。
- 毎日ログインさせる仕組み（デイリー報酬、連続ログイン、通知での呼び戻し）。
- 対戦、ランキング、サーバーを前提にする機能。
- YZRS Times 側（`yzrs-times`、`yzrswork-site`）への変更。Times Garden は公開データを読むだけの利用者。
- 実在の地球を固定の舞台にすること。惑星は号から作る架空の惑星で、地球は条件がそろったときだけ現れる伝説級とする。
